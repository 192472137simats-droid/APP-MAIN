# Project C++ Code — Demo Copy

This folder is a copy of the project's actual C++ source files. The original files remain in `cpp/`.

## Open these files during the demo

1. `src/server.cpp` — C++ HTTP service entry point and API routes.
2. `src/analysis.cpp` and `src/analysis.hpp` — LLM request handling and background analysis worker.
3. `src/paper_store.cpp` and `src/paper_store.hpp` — SQLite persistence.
4. `src/pdf_extract.cpp` and `src/pdf_extract.hpp` — PDF text extraction for the C++ service.
5. `CMakeLists.txt` — shows the C++17 build and linked dependencies.

These files retain their original names and directory layout so their roles and build structure are clear. This is a demo copy; edit the originals under `cpp/` when changing the app.
